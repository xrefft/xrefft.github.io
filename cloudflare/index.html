01 / WINDOWS

Windows

支持 x64、ARM64。按 Win + R，输入 powershell 并回车。复制下面整段命令粘贴运行，无需查找下载目录：

下载 Windows 安装脚本
$cfScript = Join-Path $env:TEMP ([guid]::NewGuid().ToString() + '.ps1')
Invoke-WebRequest -UseBasicParsing 'https://xrefft.github.io/cloudflare/install/install-windows.ps1' -OutFile $cfScript
powershell -NoProfile -ExecutionPolicy Bypass -File $cfScript

仅对本次脚本进程设置执行策略，不更改系统策略。

02 / MACOS

macOS

支持 Apple Silicon、Intel。按 Command + 空格，搜索并打开“终端”。复制下面整段命令粘贴运行：

下载 macOS 安装脚本
cfScript=$(mktemp) &&
curl -fL --connect-timeout 15 --max-time 180 'https://xrefft.github.io/cloudflare/install/install-macos.sh' -o "$cfScript" &&
sh "$cfScript"

安装到用户 Applications，注册 Cloudflare IP Test 应用。未提供 Apple 公证安装包。

03 / LINUX

Linux

支持 x86_64、ARM64。打开终端，复制下面整段运行；需要 curl、tar 和 sha256sum。桌面启动入口另需 xdg-utils：

下载 Linux 安装脚本
cfScript=$(mktemp) &&
curl -fL --connect-timeout 15 --max-time 180 'https://xrefft.github.io/cloudflare/install/install-linux.sh' -o "$cfScript" &&
sh "$cfScript"

无桌面环境仍可运行执行器，网页启动功能需要系统支持 URL handler。

如何理解结果

沿用 cloudflare-ip-ping“探测候选、按质量筛选”的思路，重新实现为跨平台 HTTPS 测试。执行器连接指定 IP，使用 speed.cloudflare.com 的 SNI、Host 和证书校验。没有使用第三方服务器代测，也不会修改你的 DNS 或代理设置。

延迟是完整 HTTPS 请求耗时；失败率是 HTTP 请求失败比例，均不同于原项目的 ICMP ping。下载速率以实际读取的数据计算，包含连接成本，并发下载会分享带宽，适合初筛。部分 Cloudflare IP 不接受此测速域名，失败不代表该 IP 对所有域名均不可用。结果不能保证特定代理协议可用。

HTTPS 测速会消耗流量。桌面版每 IP 下载 0、1 或 5 MB；iOS 默认每 IP 3 轮，每轮 1 MB。先用少量候选测试。当前预置列表只是起点，不是已验证的“最佳 IP”。

原项目 Apache-2.0 许可；本次 HTTPS 实现与原 Python ping 脚本不同。来源与许可说明 · 执行器源码
